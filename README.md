# 👨‍💻 About Me

I specialize in understanding software at its lowest levels through reverse engineering, binary analysis, and software security research. My work focuses on uncovering how executables function internally, analyzing compiled code, exploring Windows internals, and building tools that simplify complex analysis workflows.

My areas of interest include:

- Reverse Engineering
- Binary Analysis
- Executable Research
- Windows Internals
- Assembly Language
- Static Analysis
- Dynamic Analysis
- Software Security
- Debugging
- Low-Level Programming
- Automation
