About

Inside every binary
is a story.

I'm a software reverse engineer with a focus on Windows internals, binary analysis, and malware research. My work lives at the intersection of low-level systems and security research — reading what compilers produce, understanding what loaders initialize, and mapping what executables actually do versus what they claim to do.

I work primarily with PE32+ targets, tracing execution flow from entry point to deep runtime behavior. Whether it's a crackme challenge, a protocol dissection, or a Windows driver, the approach is the same: read the binary, not the documentation.

Expertise

Core disciplines.

01 / RE

Reverse Engineering

Static and dynamic analysis of compiled binaries. Reconstructing logic from disassembly, mapping control flow, identifying obfuscation and anti-analysis techniques.

IDA Pro Ghidra x64dbg CFG analysis
02 / BA

Binary Analysis

Deep PE/ELF structure inspection — headers, sections, imports, exports, relocations. Patching, instrumentation, and behavioral fingerprinting at the binary level.

PE32+ pefile Python CFF Explorer
03 / WIN

Windows Internals

NT kernel structures, process/thread internals, loader mechanics, syscall layer, Win32 subsystem, and driver architecture from ring 3 to ring 0.

WinDbg PEB/TEB SSDT Kernel debugging
04 / DBG

Debugging

Hardware and software breakpoints, conditional tracing, memory watchpoints. Navigating anti-debug, timing checks, and obfuscated exception handlers.

x64dbg WinDbg ScyllaHide TitanEngine
05 / PROTO

Protocol Analysis

Network protocol reverse engineering from packet captures. Reconstructing proprietary protocols, identifying encryption schemes, mapping command structures.

Wireshark Scapy Frida mitmproxy
06 / SEC

Software Security

Vulnerability research, exploit primitives, patch diffing, and security mechanism analysis. Understanding protections from both implementation and bypass perspectives.

CVE research BinDiff ASLR/DEP CFG
